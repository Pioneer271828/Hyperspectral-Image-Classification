# 每次训练复盘与模块有效性验收

2026-11-02起按用户要求执行。每次训练结束必须产出分析和下一步决定；改进必须由证据驱动，负结果可以导致关闭模块、保留基线或暂缓，不能强行修改参数。预登记多种子批次内只核查状态和训练/验证异常，批次完成统一作研究结论，不按中间目标测试结果改变剩余种子。

## 固定闭环

1. **先验收这次训练。**记录分支、完整SHA、输入/划分/支持集身份、更新步数、实际学习率、选模规则、权重hash、耗时与失败。训练结束不等于验收通过；失败与重试保留，不择优删除。
2. **再分析学到了什么。**训练/验证曲线、过拟合或欠拟合的证据、逐类支持数及指标、混淆、CNN/Graph/融合三路得失；未采集项明确标缺失，不凭总损失猜测。类别缺失用NA，不能当0或宣称已验证。测试只在预定最终阶段使用，不能每次试参后重看测试。
3. **核查模块是否真正参与计算。**保存实际开关和配置，确认模块被调用、参数进入优化器（若可训练）、梯度/更新有限且可观测、输出或预定中间量确有影响；监测模块记录覆盖和开销。梯度非零、激活变化不等于精度有效。冻结模块不要求梯度。
4. **做公平消融。**基线、仅开当前模块、关闭/替换当前模块保持支持标签、划分、目标预算、种子配对及选模规则一致，额外预训练/标签成本单列。可训练模块增加参数时，必要时另做容量对照。冻结模型临时关闭只能诊断依赖，不能替代关闭模块重新训练的消融；多模块叠加需独立和组合对照。
5. **判定收益和代价。**预先声明主指标及可接受退步范围；报告OA、AA、逐类指标、均值/样本标准差和配对差值，必要时边界/传感器/覆盖条件分层。记录训练与推理成本，不把共享GPU耗时直接作受控速度结论。多种子和重复任务未完成时标初筛。
6. **给出一项下一步决定并版本管理。**保留、修改、关闭或待验证；说明证据、未确定原因、下一对照、预算和预期验收条件。每次只检验一个主要变化；使用独立验证选模。模块交付后停止等待评审，不自动扩大训练。

训练结束立即保存状态摘要；如果所需分支统计、梯度或更新未采集，明确安排下一次训练前的记录接入，不能事后伪造。耗时后处理可以排队，但复盘未完成时不得把模块标为研究有效。

## 每次训练报告最小模板

- 训练身份、预算、标签预算、选模、产物和完成/失败状态。
- 与哪个冻结基线比较；仅改变什么；未控制的差异。
- 曲线、逐类与分支表现，模块执行/梯度/更新/输出影响证据及缺项。
- 主指标、配对收益、稳定性、成本；功能正确与研究收益分别判定。
- 结论：保留/修改/关闭/待验证，适用条件与限制。
- 下一次唯一主要变化、验证方案、预算、版本及停止条件。
