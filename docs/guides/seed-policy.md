# 种子、配对和正式重复规范

2026-11-02。基于用户确认，区分开发筛选、重要消融和主要论文结论。重复次数建议为3/5/10，这是本项目资源与证据需求的安排，不声称统一领域标准或已统计“大多数论文”。

- 新正式方案的训练根种子顺序固定为：`64, 512, 2048, 2026, 3407, 4096, 8192, 12345, 31415, 65536`；3/5/10次分别取前3/5/10项，不观察结果后挑选。具体实验仍须冻结完整配置与资源预算才执行。
- 数值跨度不是独立性保证，列表仅为预先固定的可复现标识。既有2036/2046/2056结果保留为开发探索性证据；匹配消融可沿用以复用控制，不因此宣称新正式列表已完成验证。
- 对比方法共享训练根种子、初始化规则、支持标签、划分和采样规则；若分流模型/新头/采样种子，映射需保存到resolved settings。既有G3用root/root+2/root+4，属于训练随机组合，不宣称单纯初始化实验。新正式完整流水线（含必要源预训练）须支持新根种子，不能只换目标种子却假装源也独立重复。
- 空间划分seed、支持标签seed与训练seed分开记录。研究训练方差时固定划分与支持；研究支持/划分稳健性另立预登记任务，空间隔离与类覆盖规则一致，不按测试成绩选择划分。固定支持的10次训练不能替代跨支持/场景重复。
- 全部重复报告，失败/异常及重试原因保留；均值、样本SD(ddof=1)、逐种子配对差值同时列出，不混用标准差与均值标准误，不将探索性种子计为独立确认。

参考原文（2026-11-02查阅）：[MSDFE, Scientific Reports 2025](https://www.nature.com/articles/s41598-025-90228-4#Sec11)报告10次重复；[PNEC-Mamba预印本附录A](https://arxiv.org/html/2608.01910v1)固定划分并报告10次重复，列出多个相邻种子；[NeurIPS checklist第7项](https://neurips.cc/public/guides/PaperChecklist)要求明确误差条捕捉的随机因素及其计算定义。这些是定向样例而非领域多数比例调查，论文的具体划分/调参做法不自动成为本项目规范。
