# 验证区冻结坐标敏感性（Issue #31）

入口 `scripts/intervene_screening_coordinates.py`；参数与消息干预入口相同，输出文件为 `coordinate-intervention.json`。
固定三个 checkpoint、原验证块、光谱、归一化统计、参数和输入维数。三个条件预先固定：original=全图归一化绝对 y/x；zero=最后两个坐标通道置零；relative=每块自身 y/(H-1)、x/(W-1)，单像素轴为零。相对坐标同时改变位置与尺度，不能只归因于平移。

用临时模型前向 hook 替换输入副本的最后两通道，正常/异常均移除。动态建图算法和参数保持原实现，但坐标经过共享特征层可能改变 Q/A；这是整条计算链的坐标输入敏感性，不是固定图的直接效应。每次回到原条件复算并核对概率容差及严格类别一致。

只运行 val，禁止覆盖已有输出目录。原条件须复现已接受的冻结诊断和原选模验证指标；状态、冻结输入、数据身份和完整 SHA 均核查。保留逐类、三路及配对纠正/损害，不能仅据第6类挑选默认结构。该诊断不训练，不访问测试分区计分，不证明坐标捷径，也不替代同预算、多种子坐标重训消融。
