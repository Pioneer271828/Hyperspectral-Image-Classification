# BN-ALIGN2: consistent validation, selection and inference

[Issue #105](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/issues/105) and [PR #106](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/pull/106) extend the accepted [BN-ALIGN1 calibration](bn-calibration.md). They reuse its pinned reference/code review; no new external code, dependency or normalization algorithm is introduced.

The original joint trainer defaults remain unchanged. The explicit `--calibrated-selection` flag creates protocol `base97_honghu_calibrated_selection_v1`. At every original validation event:

1. Save the raw current model state in a separate `raw-validation-<step>.pt` file. Calibration is bound to its SHA256 and the allowed scene/context. The file-object serialization avoids random ZIP basenames so exact continuation has stable source identities.
2. Calibrate a separate eval clone using only observations. Use that clone for both validation NLL (the scheduler input) and mean dataset fused OA (the unchanged strict-greater selection criterion; first tie wins).
3. Save raw model/optimizer/scheduler/RNG continuation state. Save the best calibrated model and receipt separately within this state; never copy calibrated statistics back into the training model.
4. Export raw `last.pt` and calibrated `primary.pt`. The selected optimizer step in the checkpoint sidecar is the actual selected cursor, independently of the total training budget. Restore and verify calibrated binding before comparing saved probabilities.

For inference use `joint_calibrated_selection.load_selected(primary, items, raw_source_path, device=...)`. It verifies state/scene/context/source binding after the normal loader. The raw source checkpoint must be kept with the calibrated classifier. A calibrated primary is an evaluation artifact; exact training continuation must use `progress.json` and the raw `state-*.pt`, never primary or last alone. Unknown policies and cross-policy resumes are rejected. Completed `--resume` verifies files and returns the original completed result without overwriting it.

All commands below run inside the authorized training container on a clean checkout at the full published SHA. Use fresh, external output directories. The preparation and training plans are unchanged.

```bash
python scripts/train_joint_baseline.py --expected-commit <SHA> \
  --profile engineering --seed 64 --calibrated-selection \
  --prepared-dir <frozen-preparation> --data-root <frozen-dataset-snapshot> \
  --out-dir <new-engineering-run>
```

The full profile requires a separately frozen experiment. BN-ALIGN2 acceptance only executes tiny synthetic optimizer updates for engineering, with zero new real-data updates.

The companion replay reads all 51 saved raw validation snapshots for each BASE97C seed (153 states). It authenticates result artifacts, cursor/schedule/history and raw model/optimizer/scheduler fingerprints, then reproduces the original validation confusion matrices and selection before evaluating the calibrated clones. It exports a separate calibrated classifier selected from the same fixed historical trajectory.

```bash
python scripts/replay_calibrated_selection.py --expected-commit <SHA> \
  --campaign-dir <base97c-full01> --prepared-dir <frozen-preparation> \
  --data-root <frozen-dataset-snapshot> --out-dir <new-replay-run> --device cuda
```

Comparisons are the original raw selected model, calibration of that original selected model, and calibrated reselection across all original states. No test-label readout or scoring occurs. The declared full-scene transductive context still observes unlabeled scene pixels; this is not strict sensor holdout. Earlier official test scores remain unchanged.

Replay cannot reproduce a new training trajectory: the original weights and learning rates were generated by raw-stat validation NLL. A future calibrated-scheduler campaign must be evaluated separately. Validation data was already inspected and is reused to select among51 states; its selected accuracy is optimistic and is not independent accuracy confirmation. Model implementation, selection replay and prospective accuracy evidence are separate gates. See the current checklist/report for acceptance, costs and the next bounded campaign.
