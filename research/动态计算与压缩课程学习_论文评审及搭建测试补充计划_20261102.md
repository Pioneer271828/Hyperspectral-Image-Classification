# 动态计算、压缩与课程学习：论文评审及搭建测试补充计划

2026-11-02；[Issue #81](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/issues/81)。三条主线仍是区域—像素互补、跨传感器光谱适配、剪枝与量化，**三条均以提升准确率为优先目标**；后续在预登记精度约束下提速。本补充登记候选与实施规则，不将其写成已实现或已提升精度。

当前已验收基准 `52ebf58b821775137932ee0048446dc3888922c5`（M1-B）。**开发主队列保持 M1-C完整/子集精度对照 → E1独立覆盖度**。M4-B2已有配对负结果，当前默认关闭；不能靠叠加这些候选隐藏负结果。每个候选单独Issue/分支/默认关闭/工程验收/效果验收/交付停止，不并行展开全部方案。

## 1. 这篇论文是什么、哪些内容有用

用户提供的正式期刊版为 Fabio Montello等，*A survey on dynamic neural networks: From computer vision to multi-modal sensor fusion*，Image and Vision Computing 170 (2026), 105980，[DOI](https://doi.org/10.1016/j.imavis.2026.105980)。28页，本地/远程SHA256一致：`a6f4a70efa5efedc8c8771e2a411a3ceb81514546776c835fb2c539ea6375de6`。已提取全部页面，重点核对第1–7、22–23页与相关原始论文；渲染检查第3、22页。期刊版包含§4.1评价模板，不能直接拿较早[预印本](https://arxiv.org/abs/2501.07451)替代；此处页码均为上传的期刊版。

对本项目最有价值的不是一个可整网替换的新算法，而是把候选拆成“输出层面的早退出、路径层面的路由、输入/区域层面的稀疏化”，并用同一精度—成本协议评价。第7页讨论课程训练、早退出训练/推理分布差异、自蒸馏及QuEE；第22页§4.1强调静态控制、整条精度—计算曲线、实测效率及固定工作点的计算量方差；第23页把少样本和小类路径训练不足列为后续问题。它们适合作为本项目工程和消融设计参考。

范围限制：文中多传感器融合主要是同时处理不同模态，**本项目跨传感器则包括不同高光谱观测条件和目标少样本适配，两者任务不同**。论文不直接证明CNN/HGCN跨传感器、小类或边界的改进；综述也不是三值压缩专论。低秩仅在引言作为静态压缩背景，三值另查TTQ原始工作。以下项目建议属于基于现有代码的研究假设。

可复核细节：第3页式(5)中低熵对应d=1，而紧接文字把d=0解释成退出，符号与文字存在不一致。实施时使用明确的 `accept_fast`/`run_full`语义与低熵/高熵两端测试，不能照抄一个含义不明的0/1。

| 动态路由/专家/条件分支 | 按覆盖条件或难度分工，可能减少负迁移并节约计算 | 简单回退和分支有效性通过之后，再评估硬路由/MoE | planned |

当前模型的具体约束：

- `forward_features`已在三路分类输出之前运行VCA、共享去噪、建图和两支路；现有CNN/Graph/融合三头不是不同深度的早退出。`torch.where`接收两个已算出的分支或事后乘门控也不省计算。
- 学习图Q/A及区域消息耦合同块像素。单独删掉“容易像素”或把困难像素裁成孤立点，会改变邻域、归一化上下文和图，不能沿用完整块等价性结论。先做整块路由；以后细化区域须保留halo、上下文及映射并单独训练/验收。
- 目前G3/M4基线实例约5.85万参数，不能照搬大ViT/ResNet的压缩倍数。先测VCA、去噪、建图、CNN、Graph、消息、分类与数据搬运的成本；参数小并不等于推理一定快，减少权重也不保证解决实际瓶颈。
- 45个开发标签每类5个，适合开发检查，不足以反复搜索复杂阈值/路由器。任何精度提升均须配对重复和独立确认；支持/空间划分重复与训练种子重复分别报告。

## 3. CUR：课程学习，分两种独立假设

[Bakhtiarnia等原论文](https://arxiv.org/abs/2104.10461)研究多出口训练，在CIFAR任务上验证早期出口改进；不是本项目少样本结论。作者代码链接已确认，实际源码/许可未完成核验（见登记表）。

### CUR-O：先做可控的观测难度课程

- [ ] 复用M1冻结记录：从完整/轻缺失到严重缺失，定义随更新步变化的调度；不改变验证扰动或完整NLL选模。
- [ ] 比较同一多重集的固定混合、随机顺序、轻→重、重→轻；各严重度总出现次数、支持标签、优化步数、图块/类别抽样与计算预算登记。若无法匹配全部曝光，明确披露差异。
- [ ] 先不同时改变样本顺序和波段增强；检查模型是否只是多看了完整数据，或末期遗忘完整观测。
- [ ] 关闭等价、确定性回放、进度/策略哈希、调度边界、单波段/缺口、训练/验证隔离测试；保存各条件训练曝光、OA/AA/NLL/逐类与梯度/更新。

### CUR-S：再做类别保护的样本课程

- [ ] 定义在允许训练支持像素上计算的损失/EMA或教师难度，冻结评分模型、时点和排序；未标注上下文不当作背景或自动伪标签。目标严格留出时只用源训练信息。
- [ ] 保留class_first的类别参与保护和每类最小曝光；在每类内部选难度或用有下限的软权重，不能一开始把少数/困难类全部删掉。所有样本最终参与，记录教师偏差及跨域误判。
- [ ] 固定混合/随机排序/易→难/难→易/仅类别平衡对照；教师评分、预热及额外训练成本单列，与等预算普通训练比较。
- [ ] 防止用本次训练的记忆损失冒充真实难度；若用支持内交叉评分，仍只消耗已允许标签，不能额外调用devval/test。课程选择不基于目标测试表现。
- [ ] 小类、第4/6类、边界（仅协议有有效标签时）、覆盖条件与源/目标分别复盘。课程提高平均OA但饿死某类时不直接推广。

CUR-O和CUR-S通过后才做二因素组合；默认不启用课程，也不改当前M1-C的公平对照。

## 4. LR：低秩分解工程与精度试验

综述参考文献[5]对应[SLR原工作及作者仓库](https://github.com/sridarah/slr)；该库存在但无可识别许可证，且为旧TensorFlow/Keras。工程优先考察许可明确的[TensorLy-Torch](https://github.com/tensorly/torch)，或直接用当前框架的矩阵分解写一个小适配器；复用数学方法与复制源码分开记录。

- [ ] 先对训练可用特征/权重统计奇异值、层级有效秩、敏感性与端到端成本，结合MON而非按激活频率单独决定秩。低有效秩不等于任意原通道可删除。
- [ ] 先选实际占成本的1×1/线性层；保留64维外部接口，以两个线性因子替换W，中间不额外插激活/归一化。深度可分卷积和很小的分类头可能已经很省，先不强制分解。
- [ ] 对m×n矩阵，忽略偏置时须满足r(m+n)<mn才减参数。例如64×64取r=48，会从4096增到6144，属于增参；r=16才降到2048。每层单独核算秩、参数与实际耗时，不能统一把“75%秩”当压缩率。
- [ ] 全秩重建数值/梯度等价、截断误差、偏置搬移、无新增非线性、设备/dtype、checkpoint分解规格/恢复及旧权重兼容测试。
- [ ] 对照原模型、分解后不恢复、分解后等预算恢复、原模型等预算微调、同参数窄模型/随机因子控制。改进精度与压缩成本分别验收，多种子配对。
- [ ] LoRA是增量适配候选，未必减少原W的推理成本；不得把LoRA参数少直接称为主干低秩压缩。图邻接低秩近似是另一个机制，不混入本轮权重分解。

## 5. TQ：三值压缩，先普通量化再尝试

[Trained Ternary Quantization](https://arxiv.org/abs/1612.01064)及[作者实现](https://github.com/czhu95/ternarynet)可参考量化与可学习缩放的设计。它在部分图像模型上存在精度改进，也有退步，不能保证本模型获益。

- [ ] 先建立FP32与常规INT8 PTQ/QAT对照，再做局部权重三值化；首轮保留VCA敏感注意力、softmax、归一化、稀疏图累加及必要首尾层高精度，明确覆盖率。
- [ ] 三值可以是{−alpha_minus,0,+alpha_plus}，不强制假设对称{-1,0,1}。保存主权重、阈值、缩放、梯度近似和优化器状态；量化边界、全零/全同号/异常值、尺度梯度、保存恢复测试。
- [ ] 区分权重三值与激活量化；用浮点tensor保存三种数值仍是浮点模拟，不等于2bit实际文件。log2(3)约1.585是信息量，不是自动实现的存储布局或GPU吞吐。计入编码填充、缩放和保留高精度层。
- [ ] TTQ/QAT与浮点等预算恢复比较，不能用额外微调归因于三值；报告小类/传感器/缺波段退化、误差传播和真实文件大小/延迟。
- [ ] 密集FP32卷积遇到零权重不会自动跳算；实测速率包含量化/解码/格式转换。若只有存储收益，按存储结果报告；若精度下降则保留浮点/INT8基线。

## 6. DY：早退出与轻模型回退，先证据后改计算图

### DY-0：离线互补与成本上界

- [ ] 对固定开发权重统计快速读出正确/完整正确的四格表、浅层正确后续改错、完整纠错潜力、两者都错、置信度/边际/熵及成本。标签只作允许验证诊断，不能出现在推理路由输入中。
- [ ] 明确上界只是oracle诊断，不宣称可部署收益。现有终端CNN头可辅助做错误互补分析，不能冒充已省掉建图的独立轻模型。
- [ ] 同一工作点按块记录路由比例和计算量分布，区分类别、边界、不同覆盖与传感器；先评估有没有足够的可节省计算。

### DY-1：最小可运行回退模块

- [ ] 两种方案分开：共享VCA/去噪前缀＋建图之前的浅出口；或独立轻模型＋完整模型。后者成本包含轻模型和失败后重算，不假定复用。
- [ ] 首个版本按空间块路由，显式延迟慢路径/建图调用。若未来按区域细分，另验收halo、Q/A映射、GroupNorm空间统计和上下文一致性。不能把已退出像素从图上下文无条件删除。
- [ ] 不只用最大softmax概率；比较熵/边际、校准后的错误概率及覆盖条件保护。未知/低覆盖观测优先完整回退，但完整模型也不保证正确；类别语义不共享时不能宣称通用闭集零样本。
- [ ] 用允许开发校准集锁定阈值。当前45标签不适合高维门控/逐类多阈值搜索，先低自由度策略并另立独立校准/确认方案；不给目标测试标签调阈值。
- [ ] 增加“强制全部完整”“强制全部快速”两个端点：前者预测/权重与原完整模型一致，后者与轻路径一致；计数器证明已接受样本不执行慢路径。测试路由顺序还原、混合批、空集合、设备/dtype与缓存生命周期。
- [ ] 首轮冻结完整模型，仅训练小出口/轻模型；再独立比较联合训练或蒸馏，并给完整模型同预算控制。不要同时改骨干、融合、采样和损失。

### DY-2：真实效果与加速验收

- [ ] 与完整模型、只用轻模型、相同回退率随机选择、同成本固定路径比较；阈值冻结后才测试，报告完整精度保护和最差类别/条件。
- [ ] 独立级联平均成本约为T_fast+T_gate+rho*T_full；共享前缀约T_prefix+T_gate+rho*T_remaining。rho为回退比例。包括分块/排序/gather/建图/同步；rho=1时级联可能更慢。
- [ ] 评价全预算曲线、同一成本区间的面积、固定配置下计算量均值/SD、接受覆盖率、错误接受率、回退纠错率、NLL/ECE和各类召回；面积定义/横轴区间预先固定，不能任意换区间比较。
- [ ] 同硬件/输入/批量、预热、CUDA同步和重复数下测中位/尾延迟、吞吐、峰值显存、模型大小；能量仅有测量工具时报告，缺失写N/A。共享GPU结果不作受控速度结论。
- [ ] “不降低精度”的容许差值及配对置信区间事前冻结；不得把均值差不显著等同于非劣。当前开发集太小，不能据此宣称无损部署。

## 7. ROUTE：硬路由/MoE与动态计算的后续边界

- [ ] 先验证上节简单回退；再评估CNN/Graph专用专家、动态深度/宽度/精度。E3/MiTA已有候选统一关联，避免重复实现。M6软交互门控属于特征调制，不自动减少计算。

- [ ] 比较单专家、所有专家稠密组合、同容量固定路由、同分配量随机路由、学得硬路由；可微门控训练与真正离散执行分开验收。
- [ ] 重排后输出顺序、无样本专家、全走一支、全走完整、上下文共享、缓存/设备/恢复一致性测试；测试调用次数而非只看门控值。
- [ ] 后续可考察量化×早退出（QuEE启发），但先单项通过；路由不得把未见传感器的测试标签变成训练信号。困难样本回退首先服务准确率保护，再考虑节省开销。
