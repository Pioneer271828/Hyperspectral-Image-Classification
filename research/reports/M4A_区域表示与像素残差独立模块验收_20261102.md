## 做了什么、有什么用

新增 `model/region_residual_decomposition.py`、16 项有针对性的测试、`scripts/validate_m4a.py` 与[接口指南](../../docs/guides/region-residual-m4.md)。调用方传入同一份 X/Q，复用已有聚合/回映函数计算区域表示 Z、区域回映 Xr 和残差 R=X−Xr；图分支可继续使用原 X 的 Z，CNN 则按独立模式选择输入。没有新增区域划分网络、标签访问或恒等重建损失。

这为研究“区域聚合是否遗漏有用的像素差异”提供可直接消融的实现。它是原定第一条研究主线的核心组件，不是继续搜索 G3 采样/LR。模块没有接入现有分类器、配置/CLI 或旧 checkpoint 包装器，原有模型默认路径保持不变；独立实现正确不能代替真实精度收益。

| 模式 | 输出给 CNN 的特征 | C=64 新增参数 |
|---|---|---:|
| none | 原 X 对象，精确旁路 | 0 |
| x_residual | [X,R] 的线性投影 | 8,256 |
| residual_only | R | 0 |
| capacity_control | X＋两层点变换，含 LeakyReLU | 8,320 |
| x_region | [X,Xr] 的线性投影 | 8,256 |

投影初始化为 [I,0]，不改变其他模块随机数序列；容量控制以第一层 I、第二层 0 保持初始恒等。两者容量接近，计算结构及参数数量并非完全一致。初始残差提示权重为零、通过该提示的 Q 梯度也为零，需经优化学起来；区域 Z 的梯度保留。容量控制第一层梯度也需第二层先离开零值。指南明确记录这些性质。

默认不返回全分辨率 Xr/R，诊断按需输出脱离计算图的标量；显式导出 Xr/R 时保留其梯度。支持 float32/float64、稠密与 COO、空区域、非连续 X；稀疏路径不把 Q 转成稠密矩阵。沿用质量下限 1e-6，微小正质量区域为衰减均值并单独计数；软 Q 的残差不保证区域均值为零或严格正交，不宣称严格高频。半精度/autocast 和实际速度尚不在本轮验收范围。
