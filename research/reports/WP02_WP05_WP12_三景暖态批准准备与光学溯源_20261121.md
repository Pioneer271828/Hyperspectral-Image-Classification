# WP12 三景暖态读取比较申请与光学来源复核

## 暖态 A/B 申请

固定三景各一个原已接受模型。PaviaU、徐州、洪湖均取模型种子 **64** 和 `target_scratch_full/none`，该选择只使用原名单字段。源计划为 PR509 使用的冻结 v2 清单。机器申请逐场景固定原检查点、架构侧车、无标签观测 ZIP、张量树摘要和原三头有序全分数摘要。申请中的两条路径分别复用原缓冲读取和第 33 包的封存映射，均实行每请求完整文件 SHA-256、原六字段、同工作量、原张量树和三头检查。快照的全文件摘要在内核封存后核验。两臂模型由同一组已验字节恢复。 [已发布原计时](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/pull/509) [第 33 包工程结果](WP12_封存观测读取归因与合成冷暖配对_20261121.md)

| 项目 | 登记内容 |
|---|---|

| 口径 | 暖态由模型驻留后的观测读入至同步物化主机三头判决。两臂保留原预制 Q/A、原格式与系统自然页缓存。模型加载、暖身、资源等待、上游制备和停表后的摘要核验单列。 |
| 指标 | 输出逐对原路径减候选的时延、两臂 p50/p95、各阶段分位数和两种顺序的配对中位数。波动宽度取两臂中较大的 p95−p50。 |

CUDA 是原计时区间的 allocator 已分配峰值。RSS 是单 worker 的进程高水位。匿名快照大小是 shmem 逻辑体量，与 RSS 同时披露，两列有可能重叠。这样的隔离比较提供读入候选的真实推理成本证据，原精度与生产默认的批准另有依据。

## 仅合成的整链路验收

同一入口依次准备机器计划和待签模板，接收单独的合成审批，再借用原加载、AB/BA 调度与 GPU 设备租约开展正常批处理。每个子进程保留原始逐行输出、进程起止时钟及 SHA-256；独审从这些原始记录重建角色、顺序、阶段时钟、每条指纹和统计。独审也用原 SHA 复核三头的聚合方式。模型和观察的数据权限由各自的固定计划来源和审批绑定。

- 复用原 36 像素无标签小例和第 33 包的三个真实尺寸合成包。36 像素有 2 对冷态与 2 对暖态，三个大包各 2 对暖态。所有暖态均各臂暖身 2 次。共通过 **4 例、12 个进程、20 次有效请求和 16 次暖身**。四份接受回执在完成重入后摘要一致。
- 缺审批、待签模板和合成审批代入真实计划的三次调用均在真实执行目录创建前拒绝。独立复制并重新固定摘要的七项合成扰动也被拒绝，分别覆盖暖身冒充实测、换权重、换观测、改一头分数、冷进程重叠、借用另一审批和倒置 AB/BA 顺序。
- 合成独审结果为 `engineering_only`。真实申请仅生成清单及待签模板。真实候选执行量、训练更新、原标签和封存 query 读取均为零。仓库检查和完整回归的精确提交回执列在交付索引。

正常复现命令在授权 LXC 执行。`RUNS` 是现有授权根，`LEGACY` 为原干净运行时，`ENGINEERING` 为新计划目录。真实待签申请保留独立路径和摘要。

```bash
taskset -c 24 python -B scripts/run_wp12_paired_observation.py \
  --runs "$RUNS" --runtime "$LEGACY" --expected-commit "$CODE" --out "$ENGINEERING" prepare --engineering
taskset -c 24 python -B scripts/run_wp12_paired_observation.py \
  --runs "$RUNS" --runtime "$LEGACY" --expected-commit "$CODE" --out "$ENGINEERING" run \
  --plan-sha "$ENGINEERING_PLAN_SHA" --approval "$SYNTHETIC_APPROVAL" "$SYNTHETIC_APPROVAL_SHA"
taskset -c 24 python -B scripts/run_wp12_paired_observation.py \
  --runs "$RUNS" --runtime "$LEGACY" --expected-commit "$CODE" --out "$ENGINEERING" audit \
  --plan-sha "$ENGINEERING_PLAN_SHA" --approval "$SYNTHETIC_APPROVAL" "$SYNTHETIC_APPROVAL_SHA" --report "$REPORT"
```
