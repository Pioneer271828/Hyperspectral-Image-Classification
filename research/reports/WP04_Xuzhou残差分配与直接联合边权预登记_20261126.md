# WP04 徐州 R3、R6 与 I7 开发预登记

依据原方案 §3.10 和 §5.11、主计划 §7/§8 与实施 §19.5。复用 #343 的同协议固定残差端点、#341 的直接消息联合边权算子、M3 原生图分配与固定邻接接口。早期 M4-B2 有 5000 步 R3，使用不同角色和种子展开。WP08 #413 的 K5/V5 块和带投影的消息对照保留原范围。WP07 的多尺度、C 的独立空间验证保持独立。

| 新格 | 输入与协议 | 总参数 |
|---|---|---:|
| R3 | 原静态 Q/A，CNN 仅见 R=X−QZ，原图支路仍池化 X | 61,696 |
| XRegion | 原静态 Q/A，CNN 见同投影的 [X,QZ]，与已有 [X,R] 等容量 | 69,952 |
| Grid0 / GridR | 本地固定网格分配、固定网格 A，CNN 见 X / [X,R] | 70,016 / 78,272 |

| I7 | 双向投影后的直接残差消息及联合边权，正边候选保持原静态图 | 111,872 |

R6 的原静态图与原生网格属于不同图族，跨图族差分作附加描述。同网格固定硬分配与可学习软分配逐种子持有同一构造器初态和同一邻接，并记录 A 指纹与 Q 稀疏度、熵、实际更新。固定网格的闲置参数和可学习分配的有效梯度分开报告。训练器使用同一三头损失，无图正则、尺度扫描或额外标签。三个比较均按原有序目标人口 BN 取各自图中的区域总体矩，校准触点保持同一公式和顺序。

I7 主比较为 I7−I6、I8−I7。I6 即 Wj，I8 为正确区域对应的门控联合边权。I0、I1、I2、I6、I7、I8 齐备才报告直接消息与门控消息各自的联合边权差中差，即 (I7−I6)−(I1−I0) 和 (I8−I6)−(I2−I0)。对齐方式、候选、监督和选模固定。I7/I8 有不同门参数，不能解释为纯等容量门效应。直接/门控的历史无边臂与联合边臂在种子 64、512 交换了 LXC 同型号 GPU 0、6，使跨格差中差同时包含这一执行差异，保留分种子设备。种子 2048 的全部交互格位于原 GPU 7。

只用徐州已发布的 9 训练点和 45 开发点，支持种子 512，模型种子 64/512/2048。复用格先校验原始审计、阶段设备、共享初态、四组监督张量摘要及终态概率。B0/R 只复用各自在原 LXC 设备上已完成的独立案例；同一批其余臂的历史失败继续保留。I0/I1/I2 来自已验收方向阶段，I6/I8 来自边权与消息对应阶段。新残差格按 GPU 0/6/7 原配对注册，I7 按 GPU 6/0/7 注册以匹配 I6/I8。每例 12 步连续、2＋10 恢复、完成重入 0。新 21 例、252 主更新及 252 恢复更新，历史复用 0 追加更新。预估 CUDA 批次墙钟 20–45 分钟，加上静态与可学习 Q 预检、独立逐点复核、成本与增量备份。

初筛判断沿用融合 OA 平均值正且至少两种子正、平均 AA 下降至多 0.5 个百分点、各类平均召回下降至多 2 个百分点。模型种子共享同一 V5 点，两个端点独立读回，每类仅五个验证点。全部为开发短测，封存 query 不参与，跨图族及不同卡窗口的效应和耗时各自指明。独立空间、异常边界、完整预算与跨场景外推留待另行登记。
