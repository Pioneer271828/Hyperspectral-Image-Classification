## 复现与回退

在授权 Linux 容器克隆完整历史，切到待验提交，在 checkout 外存放输入和测试回执。隐藏 CUDA 后执行仓库总检及定向 CPU 测试。

```bash
export CUDA_VISIBLE_DEVICES="" PYTHONDONTWRITEBYTECODE=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1
export PYTHONPATH="$PWD:$PWD/tests"
python -B scripts/check_repository.py --expected-commit "$(git rev-parse HEAD)"
python -B -m pytest -q -rs -p no:cacheprovider tests/test_m3_wp11_deployment.py \
  tests/test_wp11_native_deployment.py tests/test_integrated_deployment_cli.py \
  tests/test_wp10_unified_precision.py tests/test_wp09_registered_workflow.py \
  tests/test_wp12_decoded_cache_warm_authority.py tests/test_wp12_pavia_matched_deletion.py \
  tests/test_wp04_residual_message.py tests/test_m3_partition_freeze.py
```

CUDA 部署需显式设置已授权卡的 UUID、项目共享 `HSI_GPU_LEASE_ROOT` 及 `CUBLAS_WORKSPACE_CONFIG=:4096:8`。WP12 冻结数据恢复使用已批准的捕获和登记，通过 `scripts.ingest_wp12_evidence --pavia-matched-deletion publish` 写到新目录，再比较七份原 CSV。输入档案、权重与运行产物留在授权容器。

版本回退可在独立干净工作树从原候选 `ede473fcc5083210ccdadaf18900bc6d9275de8d` 启动，也可使用原完整 Git bundle 和其校验清单。正式主分支由项目审核流程处理。
