# WP12 完整核验的观测读取与冷暖配对

## 定位与实现

PR509 的洪湖真实暖态原报告给出约 0.91 秒读取校验、0.93 秒解码校验。此次用独立合成材料复现字节体量、张量几何和静态图数据结构。在完整核验保持一致的前提下，候选把 GPU3 洪湖暖态每对端到端耗时的中位差降低 348.4 ms，12/12 对较快。此项适用于本次授权容器和合成工作量。 [PR509 的真实发布](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/pull/509) [原计时边界](WP12_冻结54冷暖端到端实测_20261121.md)

基线每个请求从路径读取一次完整观测，随后对 ZIP 字节计算文件 SHA-256。冷态模型及侧车在进程准备阶段另行核验和加载，暖态逐请求期间模型驻留。当前 CPython 的 `BytesIO(raw)` 构造在独立追踪中只产生 80 字节 Python 分配峰值。PyTorch reader 每包进行 28 次内存 `readinto`，读取量约等于完整归档，此处把 ZIP 记录复制到新张量存储。随后对已解码张量进行独立树指纹校验。洪湖约 0.58 秒完整文件哈希和约 0.58 秒张量哈希是主要 CPU 工作，约 0.36 秒解码和存储复制提供优化空间。请求内没有重新打包序列化。Linux 进程 I/O 记账另存于原始归档，未据此核定物理磁盘读取。 [CPython 的 BytesIO 初始化与 readinto 源码](https://github.com/python/cpython/blob/842e987df856a5d4db37933c62a3456930a19092/Modules/_io/bytesio.c)

合成 Q 使用同维度的 FP32 稀疏 COO，每个像素一个非零映射，索引为 int64。A 为同维度 FP32 稠密存储，使用确定性局部环边。观测值、波长、图拓扑和模型参数均由工程生成。FWHM 字段为 None。模型从原静态结构生成，模型加载及推理沿用历史运行时 `3ba683439ed6c5ea3ae219bea0840e41b738ffce`。原整景图的区域数与每像素硬分配以已有记录为依据。 [静态图结构](E4G4D_无标签目标静态超图与真实链路验收_20261105.md)

候选在同一请求对固定源路径开一次 FD，使用 `sendfile` 复制完整 ZIP 到匿名 memfd。写入、增缩及再改封印被内核禁止后，从只读映射核验全部文件 SHA-256。PyTorch 以 `weights_only=True` 和 `mmap=True` 私有映射此快照。解码后仍核验六个无标签字段、整景像素数及完整张量树 SHA-256。每个请求重新建立并核验快照，数据内容与 ZIP 格式不变。原 v2 worker、合同和计时入口保持原代码，候选通过独立工程比较入口提供。

- PyTorch 2.7.1+cu128，运行构建源 `e2d141dbde55c2a4370fac5165b0561b6af4798b`，官方 `torch/serialization.py` 按路径调用 `UntypedStorage.from_file`，核心 LICENSE 为三条款 BSD 风格。仅调用安装环境的 API，新增外部源码为零。 [固定序列化实现](https://github.com/pytorch/pytorch/blob/e2d141dbde55c2a4370fac5165b0561b6af4798b/torch/serialization.py) [固定许可](https://github.com/pytorch/pytorch/blob/e2d141dbde55c2a4370fac5165b0561b6af4798b/LICENSE)
- CPython 3.10.20，官方发布 `842e987df856a5d4db37933c62a3456930a19092`，使用已有标准库的 `memfd_create`、`mmap`、`fcntl` 和 `hashlib`，许可见 PSF 条款。LXC Linux `6.8.0-124-generic` 实测支持所用封印，CUDA 为 12.8。 [固定 CPython 系统接口](https://github.com/python/cpython/blob/842e987df856a5d4db37933c62a3456930a19092/Modules/posixmodule.c) [固定 Python 许可](https://github.com/python/cpython/blob/842e987df856a5d4db37933c62a3456930a19092/LICENSE) [Linux memfd 接口](https://man7.org/linux/man-pages/man2/memfd_create.2.html)

## 端到端对照结果

同一 LXC 单逻辑 CPU 核 24 与物理 GPU3 两套独立测量。每景每设备 8 对冷态独立进程，暖态两臂各有一个驻留进程，各做 2 次暖身，随后 12 对实测，AB/BA 各半，模型驻留时逐请求读取相同 ZIP。冷态由父进程将要启动子进程起算，暖态从读取开始起算，两者均到物化主机三头判决。判决后的有限性核对和输出摘要留在计时窗外。文件系统缓存自然保留。节省列逐对用原路径减候选，再取中位数。正值表示较快。
