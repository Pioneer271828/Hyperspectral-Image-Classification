# G3-E4 类别参与采样完整结果

Issue #62 / PR #63。**2次源训练、8次完整目标训练、4个配对比较及产物审计全部完成。class-first在两种方法、两个探索种子上的验证OA均提高，NLL均下降，保留为待新训练种子确认的候选。**API默认仍为uniform；本完整模块交付后停止，不自动启动下一项实验。

这些是同一组45个开发验证标签上的结果，不是最终测试精度。每类5个验证标签，OA恰等于九类平均召回；每类单个样本改变召回20个百分点。只有2046/2056两种训练随机性重复，支持集和空间划分固定，多轮开发可能过拟合验证集，不能宣称统计显著、独立场景收益或普遍跨传感器优势。

所有目标训练都实际执行5000次更新；每100步验证，按融合NLL最低、同值最早选checkpoint，不按最高OA或最后一步改选。均值±样本标准差只描述这两个种子。

## 采样器是否实际起作用

候选等概率选类别，再等概率选含该类已释放训练支持的图块，仍监督图块内全部已释放标签。原balanced loss保持开启，标签仍为90训练+45验证，没有增加独立样本。类别共现使实际参与率不完全相等；隔离的是整体采样策略，不能进一步把收益单独归因于频率或上下文分布中的某一个因素。

8次训练的5000步采样均按冻结支持与seed+4完整重放一致；锚定类别、图块、理论概率和metadata hash匹配。同种子两方法的采样相同，开关前后初始骨干/新三头、支持标签、归一化统计及resolved config相同，采样序列确实改变。

| 类别 | 2046参与更新：均匀→候选 | 2056参与更新：均匀→候选 |
| --- | ---: | ---: |
| 水体2 | 432→609 | 439→617 |
| 水泥6 | 462→555 | 461→555 |
| 建筑8 | 364→597 | 322→622 |
| 其他9 | 534→676 | 529→678 |

建筑类理论参与率从6.52%变为12.50%，水体从8.70%变为12.35%，水泥从8.70%变为11.11%。这证明训练分配改变，不能仅由参与率增加保证对应类别精度提高。选定/最终权重相对初始均变化，选定权重均有限；未完整采集全程梯度和激活频率，不据此判断死神经元或剪枝价值。

两次源训练均执行10000更新：2046选8900步，源验证OA90.62%/NLL0.2403，最后NLL0.2762；2056选5600步，源验证OA85.92%/NLL0.3868，最后NLL0.4765。源验证选权重后才进行对应微调，没有源test选模；源域分数不替代目标精度。

## 下一步建议与停止点

保留class-first候选并冻结规则，不再根据这45个标签扩展采样搜索。下一完整实验建议64/512/2048新训练种子复验，源权重也按对应种子重训，保持同一配对与选模协议；这仍是训练随机性确认，不等于独立场景/支持集确认。关键结论后续按种子规范扩展重复，并另外登记空间划分/支持集/新目标传感器验证。

采样确认后推进M4区域—像素互补，重点检验裸土和CNN读出领先融合的情形；融合/分工须单独公平重训，不与采样、光谱增强同时叠加归因。剪枝、量化、MiTA不在本轮追加。**本完整模块已交付并停止，没有自动启动下一轮训练。**
