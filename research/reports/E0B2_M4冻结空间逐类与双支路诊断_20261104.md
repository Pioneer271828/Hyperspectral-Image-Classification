# E0-B2：M4冻结空间、逐类与双支路诊断

Issue #131 / [PR #132](https://github.com/Pioneer271828/Hyperspectral-Image-Classification/pull/132)。[事先固定的诊断范围](../experiments/E0B2_M4冻结空间诊断范围_20261104.md)。本模块工程与真实冻结诊断完成，没有新训练或模型推理。M4的整体收益保留，但现有证据不支持“边界、小类全面改善”。

## 本轮做了什么

新增`evaluation/spatial_prediction.py`和只读入口`scripts/evaluate_frozen_m4_spatial.py`，复用既有E0指标/四邻域定义。原预测包按split顺序存储，先核对原indices/labels，再共同排序像素、真值及三路预测，避免边界错位；无支持指标保持null/N/A。

固定none/capacity_control/x_residual、种子64/512/2048、三数据集、三头及1/2/3像素带，分别计算边界与观测非边界。主口径只使用测试区内部标签；整幅标签几何作为单列事后诊断。所有指标先复核原全测试结果，再计算空间分组和配对差。小类依据训练标签数<=25定义，全部类别、全部头均保留。

原M4-J2训练及数值重载限制不变：原三头、固定Q/A、每类1%训练/0.5%验证、同一已查看的联合划分、全景传导上下文。没有改标签比例、损失、选模或默认模型。此项是事后描述，不是新的独立划分/传感器验证，也不能用其测试表现反向挑超参。

## HongHu收益在哪里，双支路发生了什么

宽度1边界只有554/380865个测试像素，约0.15%。其余是“观测非边界”，不等于经过完整边界标注认证的物理内部。该部分融合OA **90.68→93.01%**，是全景OA提高的主要来源。

| HongHu区域/指标 | 原模型 | 残差 |
|---|---:|---:|
| 宽度1边界CNN OA | 51.50 | 54.09 |
| 宽度1边界Graph OA | 54.63 | 54.57 |
| 宽度1边界融合OA | 54.57 | 53.97 |
| 宽度1边界两路都错比例 | 30.57 | 31.77 |
| 宽度1边界恰好一路正确时融合纠错率 | 53.30 | 49.09 |
| 观测非边界CNN OA | 89.66 | 92.81 |
| 观测非边界Graph OA | 92.60 | 92.60 |
| 观测非边界融合OA | 90.68 | 93.01 |
| 观测非边界两路都错比例 | 4.26 | 3.76 |
| 观测非边界融合纠错率 | 48.78 | 57.58 |

CNN在两类区域都有变化，Graph整体基本不变；但最窄边界上同时错误增多、融合纠错降低。这里的瓶颈更像互补性与融合/监督的局部权衡，不能仅从总体CNN变好推断融合也必然变好。这是关联诊断，不足以确定唯一原因；三头共同训练结果不能替代独立支路重训。
