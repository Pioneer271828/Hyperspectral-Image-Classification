DSNet was selected as a licensed decomposition-based external reference using the author implementation at commit e910795073b52373ce0771ac85139a17f250b236 (GPL-3.0). Its abundance and reconstruction outputs are distinguished from the classification logits; only classification outputs enter accuracy and development selection. The author training script, data partitioning and test-dependent choices were not imported. The closer superpixel CNN–GCN candidates remain qualified literature references because their inspected fixed source versions did not establish the required code permissions. [Original DSNet paper](https://arxiv.org/html/2412.03893v1); [fixed author source and license](https://github.com/hanzhu97702/DSNet/tree/e910795073b52373ce0771ac85139a17f250b236).

The completed PaviaU comparison is retained as a development recipe comparison. It matches released labels, initialization seeds, update schedule and development selection opportunities, but differs in input context, architecture, objectives and capacity. It does not supply an external-method comparison under the historical S2 full-scene joint-training protocol. No matched S2–external accuracy contrast or independent spatial confirmation is reported.

To address the context discrepancy, we implemented a separate local protocol in which all methods receive the same normalized7x7 spectral observations and central labels. The native residual-off, residual-on and existing capacity-control variants share their common initial tensors; DSNet supplies the external arm. Native coordinate/wavelength inputs, learned patch graphs and method-specific objectives are stated differences. This protocol changes graph scale, normalization architecture and spatial context relative to S2, and therefore tests a new local-context question rather than reproducing or explaining the historical S2 effect by itself.

Only synthetic recovery and protocol checks have been executed for this new comparison. Its future development design requires externally reviewed original-parent footprints, uncertainty margins and source-bound role releases. Previously opened development/test labels are not relabeled as untouched confirmation. Model initialization repeats are reported separately from geographic/acquisition units. The planned K5/V5 class support permits20-percentage-point recall increments and cannot substantiate a fine-grained2-point independent uncertainty claim. Real method effectiveness, independent spatial generalization and real end-to-end cost remain unmeasured.
