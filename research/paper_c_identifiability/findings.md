## Minimum additional evidence, without opening held-aside roles

1. Bind the exact image/version hash to original retained detector-column IDs,
   bad-band deletion/merge/resampling history, calibrated per-band centers and
   usable provenance/terms. An SRF claim additionally needs measured response or
   justified response integration and its flight/device binding. Generic brochures
   and reconstructed linear center grids cannot supply this map.
2. Obtain genuinely different retained passbands with matched count/endpoints on
   the same authorized observation/context, or explicitly preregister index-stress
   experiments. Keep adapter wavelengths truthful; descriptor-only permutations
   affect only the router. Do not fix quotas per internal-mask class when estimating
   the across-mask allocation effect. Freeze exchangeability assumptions and the
   exact uniform legal-allocation null; it is not automatic causal randomization.
3. Disentangle acquisition/place/date/illumination from device using repeated
   independent acquisitions and, where possible, paired cross-device observations.
   Three model seeds and multiple tiles from one scene provide no device replication.
4. Bind source/target semantics to approved local class IDs or retain explicitly
   fresh-head representation transfer. Xuzhou's historical coal/cement names remain
   unresolved; do not silently relabel them. No shared closed-set map is active.
5. A trusted custodian and project user must release independent calibration and
   confirmation populations with immutable observation/label/use-history records,
   geography and full patch/graph-footprint review. Existing V5 remains exposed
   development. Five new points/class/role is only an engineering floor; a class
   recall guard needs a prespecified margin, multiplicity, power/disagreement and
   independent-cluster sampling design. Do not estimate these from sealed labels.
