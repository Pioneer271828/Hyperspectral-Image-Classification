# Unlabeled identifiability and recovery

Issue519; sole writer C. Branch `codex/paper-c-identifiability-20261126`, base
`c576019372a5ed7d0c91e3cc808adb8119e3b56f`. Only this directory changes.
The completed C3 experiments and their frozen producers are unchanged.

This package first binds acquisition/native retained-column provenance, roles,
band count/span/internal sampling and exact random-allocation support. Multiple
feasible assignments are necessary, not evidence of a useful coverage signal.
Unknown source calibration or unauthorized roles fail before any model/label
read. No optimization, fitting, new labels, full GT or query is authorized here.
Synthetic masks never become real sensor observations by being executable.

Operations retain source artifacts and interrupted partials while resuming the
existing full-history archive and transfer-history difference. Binary SSH relay
keeps payload in native streams/memory only; no payload or credentials on Windows.
Final publication requires the source-pinned whole-archive SHA and restoration
index checks. Target prefix hashes allow local resume-integrity checks; newly
received frame hashes alone do not prove agreement with the source until the
complete archive SHA matches. No exact cross-host training-continuation claim.
