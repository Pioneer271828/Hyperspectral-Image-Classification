# Real two-class development learning baselines (C8)

Issue527. C sole writer, branch `codex/paper-c-real-baselines-20261127`, base
`77081efa4862f6358dcce290a098e0f232fec5f8`. Only this directory may change.
Reuse the immutable C7 data/semantic/role gate and its17 preserved original tiles.
No parallel reader, new metadata/data acquisition, native-model default, shared
checkpoint interface or status-ledger change is introduced.

This package is newly authorized short real learning, following C7's data-only
admission. Its authority is separate from C7's zero-training input adapter.
No old weights are loaded. The fixed baseline is an8-dimensional, band-order-
invariant spectral-distribution descriptor plus a9-parameter binary linear
classifier; a deterministic Euclidean class-centroid reference is also included.
It is a diagnostic baseline, not a test of VCA or calibrated spectral alignment.

`protocol.json` freezes both representations, roles, fitting/selection budgets,
seeds, same-device references, statistics and failure boundaries before any real
fit. Target validation cannot choose a representation, seed, hyperparameter,
epoch or threshold. Both source/target development pools are previously exposed
and the coarse ontology is an explicitly corroborated inference, so no independent
confirmation or unqualified G2/source-only full-pipeline claim is admitted.

All scientific execution is on user-authorized rmvision. Windows holds source,
Git and deidentified review artifacts only. Raw observations, fitted parameters,
point identities and pseudonymization keys stay in the private Linux run root.
